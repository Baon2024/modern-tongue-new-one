Privacy Policy

Last Updated: November 2025

Overview

ModernTongue is a Chrome extension that translates historical English into modern language using Groq's free Llama 3.1 API. Your privacy is important to us — we designed ModernTongue to process text securely and locally whenever possible, without collecting personal data.

Data Collection & Usage

No personal data collected: ModernTongue does not collect, store, or share any personal information, browsing history, or user identifiers.

Translation data: When you request a translation, only the highlighted or pasted text is sent from your browser to your configured Vercel endpoint, which then communicates with Groq's API to generate a modern-language translation.

Local storage: Your daily usage quota (up to 50 translations per day) is stored locally in your browser using localStorage. This information never leaves your device.

API key: You provide your own Groq API key, stored privately in your Vercel deployment. The extension never accesses, logs, or transmits your key directly.

Third-Party Services

ModernTongue relies on:

  • Groq API (for text translation)
  • Vercel (as a hosting proxy for API requests)

These services may log technical data (e.g., request time, IP address) in accordance with their own privacy policies. ModernTongue does not control or retain these logs.

Offline Use

If you're offline or exceed the daily limit, translations are handled locally via an offline regex fallback. No external connections occur during offline mode.

Your Control

You can uninstall ModernTongue at any time via chrome://extensions. This removes all local data and stops all functionality. You can also reset quota data manually from Chrome's storage settings.
